# Kopi Boy Management App V1

Private management application.

- Approve/reject cook applications.
- Approve/reject rider applications.
- View approved partners.
- Enable/disable approved partners.
- View all recent orders and order status.
- Live refresh from Supabase.

Temporary management-name access is used only for staging. Replace with proper admin authentication/RBAC before public launch.


## Kopi Boy v1.1 changes
- Customer: area/postal-code food filtering and mandatory delivery address before ordering.
- Partner: first-time cook/rider compliance acknowledgement; optional SFA licence declaration for cooks.
- Management: acknowledgement/licence status visible during approval.
